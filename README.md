# Atelier Residences — Landing Page

Landing page da Atelier Residences (empreendimento Reserva Imperiale), construída em Next.js.

## Estrutura do repositório

```
.
├── frontend/   # Aplicação Next.js (código-fonte, componentes, estilos, configs)
└── docs/       # Material de referência: briefing original e assets de design
```

- **`frontend/`** — todo o projeto Next.js. Veja [`frontend/README.md`](frontend/README.md) para instruções de desenvolvimento (`npm install`, `npm run dev`, etc.).
- **`docs/`** — o briefing original do projeto (`prompt.txt`) e os assets de design (`assets/`) usados como referência visual para a construção do site.

## Início rápido

```bash
cd frontend
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).
